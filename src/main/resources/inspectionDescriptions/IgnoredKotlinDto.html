Reports @KotlinDto annotations that are silently ignored. The annotation configures the mutability of generated Kotlin DTO classes, so it only takes effect on a DTO type declaration in a module compiled by jimmer-ksp. It is dropped on a property, and ignored entirely by jimmer-apt. 


BookView {
    // @KotlinDto is dropped here
    @KotlinDto(KotlinDtoImmutability.MUTABLE)
    name
}
